👤 Добавление клиента — 3 способа

Способ 1: Контакт из Telegram 📎

  1. ➕ Добавить → 📎 → Контакт
  2. Выбери контакт из телефонной книги
  3. Клиент создаётся сразу активным и открывается его карточка с действиями

Способ 2: Фото визитки 📷

  1. Отправь фото визитки боту
  2. Бот распознаёт: имя, фамилию, телефон, email, компанию, должность, дату рождения
  3. Нажми ✅ Сохранить — клиент создаётся активным, карточка открывается сразу

💡 Телефон нормализуется автоматически: 8 999 123 45 67 → +79991234567

💡 Дата рождения распознаётся, если она есть на визитке

Способ 3: Вручную ✍️

  1. ➕ Добавить → ✍️ Добавить вручную
  2. Шаг 1/3 — введи имя
  3. Шаг 2/3 — введи телефон (или «—», чтобы пропустить)
  4. Шаг 3/3 — введи дату рождения ДД.ММ.ГГГГ (или «—»)
  5. Клиент создаётся активным, карточка открывается сразу

📅 Планирование событий

Из карточки клиента

📅 План → выбери тип события:

  • 📞 Позвонить
  • 📅 Встреча
  • 🎂 Поздравить
  • 🔔 Напомнить
  • 📝 Своё событие

→ введи описание → выбери месяц → день → час → минуты → событие создано.

Голосом 🎤

  • «Запланируй звонок Евгению на 25 декабря в 18 часов»
  • «Напомни Ивану завтра в 10:00»
  • «Запланируй встречу с Петровым 1 ноября в 15:00»

Как это работает:

  1. GigaChat парсит: тип, дату, время, клиента, описание
  2. Если тема не распознана — бот спросит «О чём звонок?» (введи тему или «—»)
  3. Покажет подтверждение → ✅ Создать / ❌ Отмена

Календарь

📅 События в меню → календарь:

  • Точки на днях с событиями
  • Клик по дню → список слотов (15-мин)
  • Клик по слоту → создать событие / открыть существующее

⚠️ Прошлое запрещено: нельзя создать событие на прошедшую дату/время. Бот откажет: «❌ Нельзя планировать событие в прошлом. Выберите будущую дату и время.»

💡 Слоты 15 минут: событие с произвольными секундами (например, 18:36:45) отображается в слоте 18:30 (округление вниз). Внутри слота видно все события этого 15-минутного интервала.

🎬 Действия с событием

Открой событие в календаре (день → час → слот → 🔍 название) — увидишь кнопки:

КнопкаЧто делает
📤 Отправить поздравление сейчасТолько для 🎂-событий: сразу отправить текст клиенту в Telegram
✅ Отметить выполненнымПомечает событие как выполненное
✏️ ИзменитьМеняет описание или тип события
🔄 ПеренестиМеняет дату/время (календарь → день → час → минуты)
🗑 УдалитьУдаляет с подтверждением (✅ Да / ❌ Отмена)

✏️ Изменить

  • 📝 Описание — введи новый текст (или «—», чтобы очистить)
  • 📌 Тип — 📞 звонок / 📅 встреча / 🎂 поздравление / 🔔 напоминание / 📝 своё
  • ⬅️ Назад — вернуться в детали без изменений

🔄 Перенести

  1. Откроется календарь (текущий месяц) — прошедшие дни ◻️ некликабельны
  2. Выбери день → час → минуты
  3. Готово: ✅ Событие перенесено, напоминание сработает в новое время

⚠️ Нельзя перенести в прошлое — бот откажет: «❌ Нельзя планировать событие в прошлом».

✅ После переноса reminder_sent_at сбрасывается — напоминание сработает заново по новой дате.

🗑 Удалить

Подтверждение: ✅ Да, удалить / ❌ Отмена. «Отмена» вернёт в детали — событие не удалится.

⚠️ Удаление необратимо. Событие исчезает из БД, календаря и напоминаний.

🔔 Напоминания о событиях

Автоматически, за 5 минут до события бот пришлёт напоминание:

🔔 Напоминание

📌 Пригласить на кофе
👤 Иван Петров
📞 +79991234567
📅 25.10 20:41

Работает через Celery Beat (каждую минуту проверяет окно [now−1м, now+5м]).

✅ Антидублирование: reminder_sent_at не даёт отправить повторно.

💡 После переноса события (🔄) напоминание сработает заново — по новой дате. Если у клиента нет Telegram ID — приходит владельцу с пометкой «отправьте поздравление вручную».

💡 Полезные советы

  • «❌ Отмена» (reply-кнопка) — сбросить любое ожидание (заметка, планирование, редактирование)
  • «—» при вводе = очистить поле
  • Телефон можно вводить в любом формате — нормализуется автоматически
  • Дата — ДД.ММ.ГГГГ (не ГГГГ-ММ-ДД)
  • Напоминания приходят только за 5 минут до события
  • Голос работает и для текстовых команд, и наоборот
  • Событие в прошлом создать/перенести нельзя — бот откажет
  • Редактирование/удаление/перенос — через кнопки в деталях события

🆘 Если что-то не работает

Бот не отвечает

Напиши /start. Если не помогло — сообщи админу.

Напоминание не пришло

Проверь:

  • событие не выполнено (is_completed=False),
  • scheduled_date в ближайшие 5 минут,
  • reminder_sent_at пусто (не отправлялось ранее),
  • бот не заблокирован.

Ошибка распознавания визитки

Сфотографируй крупнее, при хорошем свете, параллельно визитке.

Голос не распознаётся

Говори чётче, без фонового шума.

Не вижу событие в календаре

Проверь месяц/день. Слоты 15-минутные: событие 18:36:45 показывается в слоте 18:30.

Не могу перенести/создать в прошлом

Это ограничение по дизайну — прошлое запрещено. Выбери будущую дату.
